# ELIANE

Static landing page for ELIANE, maison de beaute: lavender eau de parfum, radiance cream, gold lip colour.

- `index.html` — the whole page
- `eliane.css` — house stylesheet
- Palette: lavender `#CDC2E3`, cream `#F7F4ED`, gold `#D4AF37`
- Type: Cinzel (display), Montserrat Light (secondary)

The photography and the two brand films are served from the brand CDN, so the page works from any host.
Open `index.html` locally, or turn on GitHub Pages for this repository (Settings, Pages, Deploy from a branch, main, / root).
